# SPAI-ICCE - Street View Tool

A SPAI-ICCE Street View Tool é uma ferramenta web desenvolvida para análise de imagens do Google Street View, com foco em medições remotas, calibração de imagens e apoio à verificação de excesso de velocidade.

A plataforma permite realizar medições de distâncias e alturas diretamente sobre imagens, além de oferecer recursos para calibração, comparação entre datas, carregamento de imagens locais e exportação de dados para análises posteriores.

## O que a ferramenta oferece

- Medição de distâncias e alturas em imagens
- Calibração de imagens para conversão de pixels em medidas reais
- Comparação entre diferentes datas e visualizações do Street View
- Carregamento de imagens locais para análise
- Importação e exportação de dados salvos
- Apoio a processos de análise relacionados à velocidade e à avaliação de evidências visuais

## Como usar

https://spai-icce-rj.github.io/street-view-tool/

1. Insira uma chave da API do Google Maps em campo indicado.
2. Ative os serviços necessários, como Maps JavaScript API e Places API (new).
3. Acesse a ferramenta e localize o endereço ou ponto de interesse desejado.
4. Utilize as ferramentas de medição e calibração para realizar as análises.
5. Exporte os dados gerados para uso em scripts e processos posteriores.

> Caso não seja informada uma chave própria, o acesso pode ficar limitado pela chave pública disponibilizada pelo autor.

## Observações importantes

- A ferramenta é mais adequada para uso em computadores desktop.
- Em dispositivos móveis, o funcionamento pode ser limitado.
- Para garantir o acesso à versão mais recente, recomenda-se atualizar a página com Ctrl+F5.

## Relevância do projeto

Este projeto tem aplicação em análises de imagens de rua, inspeção visual remota e estudos relacionados à reconstrução de cenas, medições e avaliação de evidências. Além disso, os dados obtidos podem ser utilizados em ferramentas de processamento posteriores para suporte a análises mais completas.
