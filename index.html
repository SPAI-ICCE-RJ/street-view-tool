Bem-vindo

Ferramenta de análise de Street View para medições remotas e calibração de imagens.

Nos sistemas Android ou iOS a ferramenta fica limitada à medições sem calibração, com medidas conhecidas ou em imagens/fotografias.

O projeto está disponível em: GitHub - SPAI-ICCE-RJ

Street View Tool

Insira sua chave da API Google Maps e ative os serviços Maps JavaScript API e Places API (new). Caso não insira uma chave própria, o acesso será limitado pelos disponíveis na chave pública do autor.

Como usar a ferramenta Street View

Passo 1: Buscar um local

Após acessar a ferramenta, use a barra de busca no topo para procurar por um endereço ou localização específica.

Passo 2: Ferramentas disponíveis
  • Régua: Mede distâncias e alturas no plano da imagem. Clique e arraste para medir.
  • Voltar/Avançar data: Navegue entre diferentes datas do Street View.
  • Uma/Duas telas: Compare imagens de diferentes fontes ou datas.
  • Carregar imagem: Carregue uma foto local para análise.
  • Carregar dados: Importe dados salvos anteriormente.
Passo 3: Calibração (IMPORTANTE)

A calibração converte medidas de pixels em medidas reais:

  1. Identifique um objeto de tamanho conhecido (ex: marca de trânsito, poste)
  2. Clique em "Calibrar SV" ou "Calibrar imagem"
  3. Use a régua para medir o objeto na imagem
  4. Insira o tamanho real em centímetros
Passo 4: Realizar medições

Com a ferramenta calibrada, use a régua para medir os objetos de interesse. Todos os pontos são registrados automaticamente.

Passo 5: Baixar dados

Quando você trabalha com uma imagem carregada e usa "Calibrar imagem" para marcar pontos de calibração, esses pontos são registrados. Clique em "Baixar dados" para salvar um arquivo dados.txt com todas os seus pontos no mundo real. Este arquivo pode ser usado no script Camera.py para calibrar uma câmera e estimar a altura de um indivíduo, cuja LR da evidência pode ser calculada por meio do script heightLR.py .

Nota: A régua é apenas para medir na tela - não salva pontos automaticamente. Os pontos são salvos quando você usa "Calibrar imagem" com uma imagem carregada.

💡 Dicas importantes:
  • Use objetos com tamanho padronizado para calibração (sinais de trânsito, linhas de estrada)
  • A ferramenta não funciona bem em celulares
  • Atualize a página com Ctrl+F5 para garantir a última versão

Verificação de excesso de velocidade com LLR

A tabela abaixo auxilia no cálculo de velocidade, tanto pela projeção reversa com dados obtidos na ferramenta acima, quanto pelo método da razão cruzada.

As incertezas e limites de errona projeção reversa são automaticamente calculadas de acordo com Harrington (2017), podendo ser substituídas por outros valores.

Na razão cruzada as incertezas e limites de erro são definidas de acordo com Mendonça (2022).

O cálculo de LR, mais especificamente do seu logarítmo, é feito traçando hipóteses de intervalos de excesso de velocidade dados pelo CTB.
